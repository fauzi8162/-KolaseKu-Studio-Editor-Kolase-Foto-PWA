# -KolaseKu-Studio-Editor-Kolase-Foto-PWA
aplikasi web progresif (Progressive Web App / PWA) berbasis HTML5 Canvas untuk menggabungkan dan mengedit kolase foto secara bebas maupun menggunakan template auto-arrange. Dirancang dengan pendekatan Mobile-First yang responsif untuk perangkat seluler (touch gesture) maupun desktop (mouse &amp; keyboard).
